AI, ML & Generative AI Online Examination
Upload `index.html` to the root of a GitHub repository and enable GitHub Pages from main / root.
The exam has 30 MCQs, 30 minutes, randomization, auto-submit, result review and a printable certificate for scores >=50%.
This is a client-side GitHub Pages quiz, so it is suitable for educational assessment but not a high-security/proctored examination.
